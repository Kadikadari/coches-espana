# CochesEspaña 🚗🇪🇸

El portal líder para la compra y venta de vehículos de ocasión en España.

## 🚀 Características
- **Búsqueda Avanzada:** Filtra por marca y por las 52 provincias de España.
- **Detalles Completos:** Galería de imágenes interactiva, ficha técnica y descripción.
- **Contacto Directo:** Botones de llamada y WhatsApp integrados para contactar al vendedor.
- **Publicación de Anuncios:** Formulario interactivo para subir vehículos de forma sencilla.
- **SEO Optimizado:** Configuración avanzada para buscadores en español.

## 🛠️ Tecnologías
- [Next.js](https://nextjs.org/) (App Router)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) (Icons)

## 📦 Instalación y Desarrollo
1. Clonar el repositorio.
2. Instalar dependencias: `npm install`
3. Ejecutar servidor de desarrollo: `npm run dev`
